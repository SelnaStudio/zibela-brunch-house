## Publicación

GitHub Pages desde la rama `main`, carpeta raíz.
URL: https://selnastudio.github.io/zibela-brunch-house/

## Conectar el dominio propio del cliente

1. En el registrador del dominio (ej. `zibelabrunch.com`), crear un `CNAME`
   `www` → `selnastudio.github.io` y cuatro registros `A` de la raíz a las IPs de
   GitHub Pages (185.199.108–111.153).
2. Agregar un archivo `CNAME` en la raíz del repo con el dominio.
3. Reemplazar `https://selnastudio.github.io/zibela-brunch-house/` por el dominio
   final en `<link rel="canonical">`, las etiquetas `og:` / `twitter:` y el
   bloque JSON-LD de `index.html`.
